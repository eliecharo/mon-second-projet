# Mon second projet

Projet d'apprentissage de Git et GitHub, réalisé un dimanche après l'autre.

## Objectif

Apprendre à travailler proprement avec les branches et les Pull Requests.

## Ce que j'ai appris

- Créer une clé SSH
- Faire un commit et un push
- Travailler avec des branches
- Ouvrir et fusionner une Pull Request

## Structure du projet

- `a-propos.md` : présentation de l'auteur
- `contact.md` : page de contact
- `jour1.md`, `jour2.md`, `jour3.md` : mon journal

**Elie Charo**, en formation GitHub.

Installation
1. Cloner le dépôt : git clone git@github.com:eliecharo/mon-second-projet.git
